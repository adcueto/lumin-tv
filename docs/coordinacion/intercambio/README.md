# Intercambio entre agentes — LUMIN TV

Referencia: `../16-coordinacion-agentes.md`, secciones 6 y 9.

Cada entrega o acuse se guarda como un archivo nuevo: `AAAA-MM-DD-HHMM-remitente-destinatario-bloque.md`. Encabezado obligatorio: PARA / DE / BLOQUE / ESTADO. Indicar ruta/versión/SHA, evidencia, pendientes y siguiente responsable. No incluir secretos ni datos operativos innecesarios.

La carpeta no envía notificaciones. Adrián transfiere el mensaje al chat receptor o autoriza el canal correspondiente. No modificar los mensajes de otro agente ni afirmar que fueron leídos sin acuse.
